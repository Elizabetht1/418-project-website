## Summary

We are implementing a parallel Sequence-to-Graph aligner that maps long DNA reads (>1,000 characters) to pangenome variation graphs, using both inter-sequence and intra-sequence GPU parallelism via CUDA on NVIDIA RTX 2080 GPUs.
